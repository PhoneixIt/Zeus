1. ROADMAP OVERVIEW (from PDF validation)
================================================================

The AIOS Master Roadmap is a 6-phase plan for building an autonomous,
cross-platform capability system with a strict $0 budget constraint.

Key constraints highlighted:
- $0 budget: No paid hosting, subscriptions, API usage, purchases
- Local-first: Use existing laptop, local open models first
- Verification is independent: Task complete only when evidence passes checks
- Autonomy with bounded authority: Safe work autonomously, destructive actions need gates
- Cross-platform via adapters: Core separated from platform-specific code
- One source of truth: Shared task state, permissions, observability

Phase summaries:
- Phase 3 (current focus): Stabilize execution foundation
  * Persistence, atomic locks, duplicate-task handling
  * Verification/refinement, deterministic tests, safe shutdown/resume
- Phase 4: Secure capability and connector framework
  * Adapters for local tools, browser/desktop control, filesystem
  * Command execution, APIs, tool servers, remote devices
- Phase 5: Zero-cost infrastructure decision framework
  * Compute, models, hosting, storage, automation decisions
  * All decisions must respect $0 constraint
- Phase 6: Definition of done
  * Evidence-based acceptance checklists
  * Architecture, feasibility, reproducibility, capability discovery, integration
